# Step by step

This tutorial goes through the main features of `acids-dataset` on a small dataset that we generate ourselves, such that every code block can be run as is, in order. Each page introduces one notion, and links to the [documentation](../guide/index.md) for details.

| Step | You will learn to |
| ---- | ----------------- |
| [1. Installation](01-installation.md) | install `acids-dataset`, and generate the tutorial dataset |
| [2. A first dataset](02-first-dataset.md) | load an audio folder, read items and files, build a data loader |
| [3. Features](03-features.md) | compute descriptors, and extract metadata from file names |
| [4. Outputs and augmentations](04-outputs-augmentations.md) | shape outputs, and augment audio |
| [5. Partitions](05-partitions.md) | split datasets into reproducible partitions |
| [6. Pre-processing](06-preprocessing.md) | compile a dataset, and check its health |
| [7. Training](07-training.md) | balance classes, follow a curriculum, train with Lightning |
| [8. Going further](08-going-further.md) | presets, combined datasets, the dataset browser |

The tutorial runs on CPU in a few minutes.
